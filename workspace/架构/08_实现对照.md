## 4. 01 记忆分级关联性系统

| 设计层级 | 实际落盘 | 状态 |
|---|---|---|
| L0 工作记忆（内存环形） | 对话上下文在 `HomeAgent` 进程内维护；直播短期上下文 `state/live-context.json` | 已实现 |
| L1 短期记忆（`memory/YYYY-MM-DD.jsonl`） | `workspace/memory/*.jsonl` 每日记忆（字段 `id/time/type/user/privacy/tags/content/category/importance/source`） | 已实现（路径为 `workspace/memory/`，非根 `memory/`） |
| L2 长期记忆（SQLite/向量索引） | **`LongTermMemory/memory.db`**（SQLite）：`store()` 硬校验——类别必须高价值、`tags` 3–5、`summary` 1–20 字、`importance≥70` | 已实现（**无向量索引**） |
| L3 知识固化 | `workspace/CHARACTER.md`、`RULES.md`、`HOME_RULES.md`、`LIVE_RULES.md`、`ABILITIES.md` | 已实现 |
| 关联图谱 / 向量召回（Edge + graph 扩散） | **设计待实现**：当前检索为结构化字段 + 标签/`importance` 过滤，无图遍历、无 embedding | 未实现 |

**关键约束（开发易踩）**：长期记忆 `store()` 不满足硬校验直接抛错；`memory_write.importance_threshold: 70` 与 `always_keywords`/`ignore_keywords` 在 `config.yaml` 中定义（注意：AI Read 06 称已移除本地关键词兜底，以记忆模型判断为准，二者以当前代码为准）。

## 5. 认知 / 规划层 + 02 任务排序系统

| 设计概念 | 实际实现 | 位置 |
|---|---|---|
| LLM 推理（OpenAI 兼容） | `LLMClient`（DeepSeek/MiMo/Custom）、`MiMoMultimodalClient` | `modules/live/ai_live_assistant/llm.py`、`HomeAgent/home_modules/mimo_multimodal.py` |
| 语义规划器（`visual_required`/`interaction_mode`/`code_scope`） | `HomeAgent.agent` 总规划：是否任务、回答/执行/追问、能力、工具、步骤、成功条件 | `HomeAgent/agent.py` |
| 任务调度（优先级抢占/资源锁/EDF） | 单 `ChatWorker` FIFO 串行消费；直播语音 PriorityQueue 单消费者；`Task/*.json` 提醒由调度器写 | `HomeAgent/qt_app.py`、`Skill/schedule-home-task/scripts/task_manager.py` |
| 工具循环（28 轮失败预算 / 112 总上限） | 模型驱动工具循环，原子工具返回结构化事实；`begin_task` 仅 `domain=code & code_scope=self` 进自升级 | `HomeAgent/agent.py`、`home_modules/code_editor.py` |
| 完成检查（独立模型核验） | 消费本地工具证据，`fail_closed`；伪造 `<tool_call>` 拒绝 | `mimo_multimodal.completion_check` |

> 设计为"多 worker 并发 + 独立 `TaskScheduler` 模块"；实际为**单消费者串行**（避免资源争用/语音重叠），更保守。
