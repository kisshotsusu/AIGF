# 05 设置接口与参数系统

> 配置是 Agent 的"控制面板"。所有输入源、LLM 接口、音频输出、记忆与调度参数都集中在此定义。真实系统采用**双 YAML + config.d 拆分 + 角色工作台单一写入权威**（整合 AI Read 03/05），本文件据此校正原绿地设计。

---

## 1. 目标与定位

- 集中管理：输入源、LLM 接口、音频输出接口、记忆/调度/感知参数。
- **单一写入权威 = `CharacterService`（角色工作台）**：经它双向同步 `HomeAgent/config.yaml` 与 `config.d/*`，UI 必须保留未知字段。
- 安全：密钥只存 `.env`，敏感字段走环境变量。

---

## 2. 真实配置文件结构

| 文件 | 职责 | 备注 |
|------|------|------|
| 根 `config.yaml` | 直播 + 共享工作区 | 直播核心、共享 `workspace` 路径 |
| `HomeAgent/config.yaml` | 家庭桌宠与自动化 | 家庭/麦克风/桌面宠/STT/agent/语义规划/视觉/电脑控制 |
| `HomeAgent/config.d/*.yaml` | 维护项拆分视图 | `computer_control` / `vision_mcp` / `context_maintenance` / `context_cleanup` |
| `workspace/MCP_SERVERS.yaml` | MCP 注册（同步到 WorkBuddy/Codex） | 保留未修改项 |
| `.env` | 密钥（**只此一处**） | `DEEPSEEK_API_KEY`/`MIMO_API_KEY`/`CUSTOM_API_KEY`/`IMAGE_API_KEY`/`DASHSCOPE_API_KEY`/`XAI_API_KEY`/`STT_API_KEY`/`BILIBILI_COOKIE` |

> **config.d 双向同步**：`CharacterService` 按修改时间（mtime）判定主配置覆盖拆分文件或反之；`save_config_section` 同时写两处并保留 UI 未识别字段。**手改其一后，下次经服务读取可能被另一处旧值覆盖**——改配置应走角色工作台或两处一并修改（AI Read 05）。

## 3. 输入源配置（覆盖用户原始需求）

每个输入源是 05 中的具名能力，可多实例并存：

```yaml
# 桌面输入 → Vision desktop_*/window_* + vision_mcp.gui_enabled
vision_mcp:
  gui_enabled: true
  preload_model: false

# 网络摄像头输入（设计演进 ★）
camera:
  enabled: false
  device_id: 0
  resolution: "640x480"

# 网络视频输入 → 视频理解与编辑
qwen_video_understanding:
  provider: mimo
  fallback_provider: qwen
  fps: 1
video_editing:                # 原子工具 cut/concat/subtitle/voiceover
  enabled: true

# 麦克风/系统音频 → Sound MCP + microphone/stt
microphone:
  sample_rate: 48000          # 首选，失败回退设备原生/默认
stt:
  mode: sound_mcp             # sound_mcp|mimo|api|local
```

**类型枚举**：`network_video` / `desktop` / `webcam` / `microphone` / `system_audio` / `network_audio`。

## 4. 大语言模型接口（OpenAI 兼容，主模型 MiMo）

```yaml
llm:
  provider: openai-compatible
  timeout_seconds: 30
  live:   {temperature, max_tokens}      # 直播场景
  home:   {temperature, max_tokens}      # 家庭场景
  memory: {temperature, max_tokens}      # 记忆分类场景
  providers:
    mimo:
      base_url: "https://api.mimo.com/v1"
      model: "mimo-v2.5"
      auth_header: api-key
      max_tokens_field: max_completion_tokens
      supports_images: true
      extra_body: {thinking: {type: disabled}}
    deepseek: {base_url, model: deepseek-chat}   # 纯文本，不声明 supports_images
    custom:   {base_url, model}
mimo_multimodal:                          # 图片/ASR/完成检查共用
  enabled: true
  image_model: mimo-v2.5
  asr_model: mimo-v2.5-asr
  completion_retry: 2
  fail_closed: true
  deepseek_image_enabled: true            # DeepSeek 视觉代理兜底
semantic_planner:                        # MiMo 总任务判定与计划
  enabled: true
  timeout_seconds: 10
  minimum_confidence: 0.55
  context_messages: 8
  max_tokens: 900
```

## 5. 音频输出接口

```yaml
tts:                                     # GPT-SoVITS :9879
  url: "http://127.0.0.1:9879"
  health_url: "/api/options"
  health_timeout_seconds: 6
  timeout_seconds: 60
  retry_attempts: 4
  retry_delay_seconds: 2                  # 指数退避，单次上限 15s
  start_batch: ...                         # 防重复启动批处理
cosyvoice_tts:                           # CosyVoice2 :50000（当前 enabled:false）
  enabled: false
  endpoint: "http://127.0.0.1:50000"
singing:
  mode: local_tts                         # MiMo mimo-v2.5-tts 为关闭的备用分支
```
> 文本在传给外部 SVC 前按 GBK 过滤 emoji，避免中文路径/编码乱码；TTS 失败降级 Windows SAPI。

## 7. 模块结构（设计目标）

```
ConfigManager
├── Loader        # 读双 YAML + config.d + 环境变量插值(${ENV:VAR})
├── Validator     # 校验（参考 config/settings.schema.yaml）
├── Syncer        # CharacterService 双向 mtime 同步（真实已实现）
├── AtomicWriter  # 原子临时文件替换 + 未知字段保留
└── PubSub        # 变更订阅（模块刷新参数）
```

---

## 8. 接口契约（设计目标）

```python
class ConfigManager(Module):
    def get(self, path: str) -> Any
    def set(self, path: str, value: Any) -> None
    def validate(self) -> list[Issue]
    def reload(self) -> None
    def subscribe(self, path: str, cb) -> None
```

---

## 9. 关键规则（整合 00 安全边界）

1. **单一写入权威**：`CharacterService` 管理共享模型/密钥；直播控制台只维护运行参数与 `BILIBILI_COOKIE`（AI Read 03）。
2. **密钥不明文**：`api_key` 一律 `${ENV:VAR}`，文件不写明文；密钥只存 `.env`。
3. **原子写 + 未知字段保留**：设置保存用临时文件替换，UI/服务必须保未知字段。
4. **环境变量插值**：`${ENV:VAR}` 缺失即报错，不静默。
5. **校验先行**：加载/热更新后必须 `validate`，不合法拒绝生效并告警。
6. **不覆盖保护**：直播网页旧值不得覆盖角色工作台已迁移的 `llm/tts/image_generation/memory_write/workspace` 等（AI Read 03）。

## 10. 配置字段约束摘要（详见 config/settings.schema.yaml）

| 路径 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `llm.providers.mimo.base_url` | url | 是 | OpenAI 兼容端点 |
| `llm.providers.mimo.model` | string | 是 | `mimo-v2.5` |
| `tts.url` | url | 是 | GPT-SoVITS `:9879` |
| `vision_mcp.gui_enabled` | bool | 是 | 视觉能力开关 |
| `computer_control.full_access` | bool | 否 | 代码工具绝对路径授权 |
| `microphone.sample_rate` | int | 否 | 首选采样率，失败回退 |
| `mimo_multimodal.fail_closed` | bool | 否 | 核验失败默认判失败 |

---

## 11. 与其他系统关系

- **→ 所有系统**：唯一参数供给方（双 YAML + config.d）。
- **被 00 规则约束**：密钥、权限、安全边界在此落地。
- **热更新联动**：切换输入源/LLM/TTS 时，对应子系统通过 `subscribe` 刷新（如 Vision `gui_enabled` 由角色管理器控制，禁用时停止旧视觉模型进程）。
