# 04 模拟输入系统

> 执行是 Agent 的"手"。本系统把认知层下发的抽象动作（点击某元素、输入文本、打开应用、执行命令）变成真实电脑操作，并受权限与安全规则约束。本文件整合真实实现（AI Read 02/03），标注「设计演进」。

---

## 1. 目标与定位

- 模拟键盘、鼠标、触屏输入；启动应用、执行受控 shell、操控窗口。
- 与视觉系统协同，实现"看到→点击"的闭环。
- 所有动作受权限分级、确认、审计约束（见 00 安全边界）。

---

## 2. 真实动作工具（已实现，经 Vision MCP / 本地模块）

### 2.1 视觉/窗口/桌面（Vision MCP `:8765`）
- GUI 视觉后端（GUI-Actor / GUI-Owl 双后端）：`click(instruction)` / `type_text` / `type_active_text` / `ground_page` / `scroll` / `wait` / `play_video` / `screenshot` / `inspect_active_target`
- 窗口：`list_windows` / `activate_window` / `window_screenshot` / `window_click` / `window_double_click` / `window_type_text`
- 桌面：`desktop_screenshot` / `desktop_click` / `desktop_type_text` / `desktop_type_active_text` / `desktop_read_clipboard` / `desktop_scroll` / `desktop_hotkey`
- 网页 DOM：`navigate` / `get_url` / `web_read` / `web_click_text` / `web_fill` / `web_press` / `web_play_media`

### 2.2 命令执行（HomeAgent `command_executor`）
- `command_executor`：执行规划后的 PowerShell/CMD，统一工作目录、超时、输出与失败状态。

### 2.3 浏览器控制（HomeAgent `edge_browser`）
- `edge_status` / `edge_open_url` / `edge_open_chatgpt` / `edge_eval_js` / `edge_screenshot`：经 CDP 直连 Edge（优先复用已有端点，否则自动拉起独立用户目录实例）；`edge_status` 可列 `chrome-extension://` 插件页。

### 2.4 媒体与进程（原子工具）
- `media_stop()`：幂等 `WM_APPCOMMAND_MEDIA_STOP`，停止播放不关播放器（≠ Space）。
- `close_app` / `terminate_process` / `process_status`：`process_status` 把"进程不存在"规范为 `ok=true,running=false`，避免误判失败。

### 2.5 扩展能力（设计已实现）
- `comfyui_client`（`:8188` 图像/视频生成）、`cosyvoice_tts`（`:50000` 情绪 TTS，当前 `enabled:false`）、Codex CLI、Skill 技能、文件/代码工具 —— 均由模型按任务选择，与本地工具并列。

## 3. 动作原语（设计抽象，映射真实工具）

```yaml
Action:
  kind:   enum   # click|type|hotkey|scroll|launch|shell|window_ctrl|media|browser
  target: any    # 坐标 / 语义描述（由 03 latest_frame 解析）/ 应用名 / 命令
  params: dict
  permission: enum # read|ui|system
  reversible: bool
```
- **逻辑坐标**：GUI 视觉后端返回归一化与像素坐标（GUI-Actor 0~1，GUI-Owl 0~1000 代码内 `/1000`）；语义目标（"登录按钮"）由 03 `ground_page`/`desktop_click(instruction)` 解析为坐标。

## 4. 模块结构（设计目标）

```
InputController
├── ActionValidator   # 权限/参数/安全校验（真实：computer_control 配置）
├── Coordinator       # 资源锁（鼠标/屏/麦 单任务独占）
├── ToolBridge        # 调 Vision MCP / command_executor / edge_browser（真实后端）
├── VisualResolver    # 调 03 latest_frame 把语义目标解析为坐标
├── Verifier          # 操作后截图回看验证（550ms 协议）
├── UndoStack         # 可逆动作撤销
└── AuditLog          # system 级动作审计
```

## 5. 操作后验证协议（关键，真实已实现）

> 所有点击/输入/快捷键/滚动后 ~550ms 重新截图，返回证据；模型只采用同一对象的最新有效证据。

```yaml
ToolResult:
  ok: bool
  observation/result: any
  error: Error|null
  tool_submitted_at, tool_completed_at, tool_elapsed_ms, tool_sequence
  # 视觉工具另带：
  screenshot_captured_at, observed_at
  state_changed: bool
  post_action_verified: bool
  actual_target: any          # 实际作用对象
```
- 较新同对象证据覆盖旧证据；分析期间状态已变化的结果立即废弃；过期证据从完成证据中淘汰。
- **不虚构成功**：仅验证终态（URL/文本/媒体实际播放）后汇报；核验模型 `fail_closed` 时不得报告完成。

## 7. 本系统特有规则

1. **权限强制**：`ui` 动作需 `computer_control` 授权；`system`（shell/删除/安装/联网）需显式二次确认 + 审计（见 00 安全边界）。`computer_control.full_access` 授权绝对路径列举/读/搜/原子写/替换；关闭时仅限 `allowed_roots`；`.env`/PEM/KEY/PFX 始终拒绝。
2. **资源互斥**：鼠标/屏幕/麦克风同一刻只归一个任务，由 02 调度器资源锁保障；Vision 工具固定单线程。
3. **可逆优先**：删除/移动等动作执行前先记录原状态，支持 `undo`；不可逆动作强制确认。
4. **执行可验证**：关键动作后截图/读状态回看，确认成功或触发重试。
5. **绝不伪装**：不伪造已执行的操作结果（沿用 RULES.md 第 7 条）。
6. **登录态保护**：不启动临时浏览器、不关闭用户现有浏览器。
7. **降级为建议**：输入后端不可用时，转为"建议模式"只给指令不执行。

## 9. 与其他系统关系

- **← 02 任务**：计划 `steps`/`preferred_tools` 即动作，由本系统落地。
- **↔ 03 感知**：`VisualResolver` 依赖 03 `latest_frame` 做坐标解析与执行验证。
- **→ 01 记忆**：执行结果（成功/失败经验）回写记忆，形成"试错学习"。
- **依赖 05**：权限级别、确认规则、后端选择来自配置。
