# 03 视觉与音频识别系统

> 感知是 Agent 的"眼"与"耳"。本系统把多种输入源（网络视频、桌面、摄像头、麦克风、系统音频）统一成**结构化感知事件**，供记忆与认知层消费。本文件整合真实实现（AI Read 02/03），并标注「设计演进」。

---

## 1. 目标与定位

- 多源采集：网络视频、桌面屏幕、网络摄像头、麦克风/系统音频。
- 视觉识别：DOM/CDP 网页、GUI-Actor / GUI-Owl 视觉点击（双后端）、窗口/桌面工具、OCR、场景理解。
- 音频识别：ASR（SenseVoice）、VAD、说话人/语言识别。
- 统一输出 `PerceptionEvent`，非阻塞投递到总线。

---

## 2. 真实能力层（已实现，经 MCP/本地服务）

### 2.1 Vision MCP — `127.0.0.1:8765/mcp`
默认 `stdio`，`VISION_MCP_TRANSPORT=http` 时以 `streamable-http` 暴露；HomeAgent 经 `http://127.0.0.1:8765/mcp` 连接。所有网页/GUI 工具固定在单一专用线程（`max_workers=1`）共享浏览器会话。

**网页 DOM/HTML 优先（无模型）**：`navigate` / `get_url` / `web_read` / `web_click_text` / `web_fill` / `web_press` / `web_play_media`
**GUI 视觉工具（GUI-Actor / GUI-Owl 双后端，需 `gui_enabled`）**：`click` / `type_text` / `type_active_text` / `ground_page` / `scroll` / `wait` / `play_video` / `screenshot` / `inspect_active_target`

> **视觉后端：GUI-Actor 与 GUI-Owl 双后端，按 `VISION_BACKEND` 选择**（2026-09-01 整合验证）
> - `gui_actor`（默认）：`GUI-Actor-2B-Qwen2-VL` pointer-head，输出 0~1 归一化坐标；依赖 transformers 4.51.3，运行于共享 `.venv`。
> - `gui_owl`（**当前活跃后端**）：`GUI-Owl-1.5-2B-Instruct`（Qwen3-VL 原生 GUI agent），生成式 `<tool_call>` JSON + 0~1000 坐标（代码内 `/1000` 归一化）；依赖 transformers≥4.57，现已随共享 `.venv` 升级到 4.57，与 GUI-Actor 同 env 运行（已验证 GUI-Actor 在 4.57 下仍正常）。
> - 选择：`vision_mcp.backend` 配置项 或 环境变量 `VISION_BACKEND`；HomeAgent 统一用共享 `.venv` 拉起服务（见 `HomeAgent/agent.py` 视觉服务启动逻辑）。
> - **验证状态**：GUI-Owl 已实跑切换至 8765，`vision_backend()` 返回 `backend=gui_owl, loaded=True, device=cuda:0`；直接推理定位偏差 0.3~0.6%，找不到元素正确 `terminate`；MCP 服务端运行时验证通过（32 工具可调、模型驻留 GPU）。
> - **坑**：MCP 服务端依赖必须 `mcp<2`（`mcp` 2.x 把 `FastMCP` 改名为 `MCPServer`，直接 ImportError）。GUI-Actor 与 GUI-Owl 互斥（同实例锁 `Vision/state/vision-mcp.lock`、同端口 8765），切换前先停另一实例。
**窗口工具**：`list_windows` / `activate_window` / `window_screenshot` / `window_click` / `window_double_click` / `window_type_text`
**桌面工具**（整屏视觉）：`desktop_screenshot` / `desktop_click` / `desktop_type_text` / `desktop_type_active_text` / `desktop_read_clipboard` / `desktop_scroll` / `desktop_hotkey`
**诊断**：`vision_memory_status`（CUDA 显存）

### 2.2 Sound MCP — `127.0.0.1:8766/mcp`
- `transcribe_file(path, language="auto")`：`auto/zh/en/ja/ko/yue`，只返回清洗后纯文本。
- `record_and_transcribe(duration, language)`：协商设备采样率后录音并转写（SenseVoice）。

### 2.3 MiMo 多模态（图片/ASR/完成检查共用 `mimo_multimodal` 配置）
- 图片理解：`mimo-v2.5`；语音识别：`mimo-v2.5-asr`；完成检查模型独立、默认重试 2 次、`fail_closed`。
- DeepSeek 视觉代理方案：纯文本 DeepSeek 经视觉代理模型（默认 MiMo）把图片转文字描述再推理，`analyze_image` 优先走 DeepSeek，失败回退 MiMo。

### 2.4 视频理解（设计已实现）
- `qwen_analyze_video` / `VideoUnderstandingClient`：默认 MiMo V2.5、Qwen/DashScope 兜底，输出带 `start/end/event` 的事件时间轴；不含剪辑/拼接/字幕逻辑（见 AI Read 06）。

## 4. 视觉路由：inspect_active_target

```text
browser_dom      : 现有 Chrome/Edge 暴露 CDP → web_read/web_fill/web_click_text
browser_visual   : 浏览器存在但无 CDP → 保留该浏览器 + 窗口截图 + GUI 视觉后端（GUI-Actor / GUI-Owl）
desktop_visual   : 当前程序非网页 → Windows 窗口/桌面工具
```
> 路由**只依据模型计划字段**（`visual_required` / `interaction_mode` / `inspect_active_target` 的机械能力事实），不依据关键词表。

## 5. 统一输出（PerceptionEvent）

```yaml
PerceptionVision:
  source, timestamp, frame_id
  detections:    [{label, bbox, score, track_id?}]
  ocr_text, ocr_blocks
  scene_label, vlm_caption
  faces:         [{bbox, expression?, age?, gender?}]
  raw_ref
PerceptionAudio:
  source, timestamp, transcript, language, speaker, is_speech, events[], confidence
```
> 视觉结果须携带截图采集时间与分析完成时间；较新同对象证据覆盖旧证据；分析期间状态已变化的结果立即废弃。

## 6. 模块结构（设计目标）

```
PerceptionSystem
├── SourceManager      # 按 05 配置启停输入源（真实：Vision/Sound MCP 客户端）
├── VisionPipeline     # DOM/GUI 视觉后端（GUI-Actor/GUI-Owl 双后端）/窗口/桌面（真实：Vision MCP 工具编排）
├── AudioPipeline      # VAD/ASR/说话人（真实：Sound MCP + MiMo ASR）
├── MultimodalClient   # 图片/视频理解、完成检查（真实：MiMo 多模态）
├── PerceptionBus      # 统一事件总线，非阻塞发布
└── Cache              # 最近帧/最近音频缓存（供 04 定位）
```

## 8. 本系统特有规则

1. **DOM 优先**：网页任务优先 CDP/DOM，无 CDP 才回退窗口视觉，不启动临时浏览器。
2. **模型决定视觉**：是否读屏只由 `visual_required` / `interaction_mode` 决定，不看关键词。
3. **视觉模型懒加载（双后端）**：`gui_enabled:true`、`preload_model:false` —— 允许但启动不预占显存；`VISION_PRELOAD_MODEL=1` 可覆盖。后端由 `vision_mcp.backend`（`gui_actor`/`gui_owl`）选择；`gui_owl` 经共享 `.venv` 运行，模型为 GUI-Owl-1.5-2B（Qwen3-VL，BF16 约 4GB 显存）。
4. **操作后可验证**：每次点击/输入/快捷键/滚动后默认 ~550ms 重新截图，只返回状态变化证据（详见 04 §5 验证协议）。
5. **按需推理**：VLM/大模型描述默认关闭，仅认知层显式请求或检测/OCR 不足时触发。
6. **隐私红区**：摄像头/麦克风在 `secret` 模式外不持久化原帧；原帧缓存带 TTL 清理。
7. **降级链**：视觉模型挂 → 退 OCR/DOM → 退无感知；音频模型挂 → 退文本。

```yaml
  backend: gui_owl                # gui_actor | gui_owl；两者统一运行于共享 .venv
  gui_owl_model: Vision/models/GUI-Owl-1.5-2B-Instruct

  existing_browser_cdp: ...        # 现有浏览器 CDP 端点

  enabled: true
  image_model: mimo-v2.5
  asr_model: mimo-v2.5-asr

  fail_closed: true

  provider: mimo
  fallback_provider: qwen
  fps: ...
microphone:
  sample_rate: 48000               # 首选，失败回退设备原生/默认
stt:
  mode: sound_mcp|mimo|api|local
```

## 10. 与其他系统关系

- **依赖 05**：输入源清单、模型选择与端口来自配置。
- **→ 01 记忆**：结构化结果作为 `event`/`fact` 写入。
- **→ 认知层**：实时事件驱动任务生成（如"有人进房"）。
- **↔ 04 执行**：`latest_frame` 供执行层做视觉定位点击；执行后验证截图由本系统提供。
