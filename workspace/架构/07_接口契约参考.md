## 1. 统一模块生命周期接口

```python
class Module:
    def initialize(self, config: dict) -> None   # 读 05 配置，分配资源；失败须抛错
    def process(self, payload: Any) -> Any        # 主处理逻辑
    def get_status(self) -> dict                  # 健康/队列/指标
    def shutdown(self) -> None                     # 幂等释放，保证落盘
```

## 4. 工具通用返回契约（03/04，强制）

```yaml
ToolResult:
  ok: bool
  status: string
  observation|result: any
  error: Error|null
  tool_submitted_at: datetime
  tool_completed_at: datetime
  tool_elapsed_ms: int
  tool_sequence: int
  # 视觉/窗口/桌面工具另带：
  screenshot_captured_at: datetime|null
  observed_at: datetime|null
  state_changed: bool|null
  post_action_verified: bool|null
  actual_target: any|null
```
> 模型只采用同一对象的最新有效证据；旧序号、早于后续动作或与当前对象不一致的结果应废弃（AI Read 03）。

## 6. 核心数据模型字段表

### 6.1 长期记忆记录（01，真实 `LongTermMemory/memory.db`）
`id, created_at, user_id, scene, category, tags[3-5], summary(≤20字), detail, importance(≥70), privacy, source`

### 6.2 每日共享记忆（01，真实 `workspace/memory/YYYY-MM-DD.jsonl`）
`id, time, type, user, privacy, tags, content, category, importance, source`

### 6.3 直播短期上下文（01，真实 `state/live-context.json`）
`角色, 内容, 创建时间`；默认清理 >120 分钟。

### 6.4 定时任务（02，真实 `Task/<id>.json`）
提醒/闹钟/周期任务唯一持久化；一次性成功后删除。

### 6.5 PerceptionEvent（03）
- 视觉：`source, timestamp, frame_id, detections[{label,bbox,score,track_id?}], ocr_text, ocr_blocks, scene_label, faces, vlm_caption, raw_ref`
- 音频：`source, timestamp, transcript, language, speaker, is_speech, events[], confidence`

### 6.6 Action / ToolResult（04）
- Action：`{kind, target, params, permission:read|ui|system, reversible:bool}`
- ToolResult：见 §4

## 9. 术语表（Glossary）

| 术语 | 含义 |
|------|------|
| 模型驱动规划 | 任务意图/类型/步骤/工具选择由 LLM 决定，本地不硬编码（最高优先级规则） |
| 工具原子性 | 工具只做单一可验证动作并返回结构化事实，不判完成 |
| fail-closed | 核验/接口异常时默认判失败，不报告完成 |
| InstanceLock | 跨进程文件锁，常驻服务单实例约束 |
| GUI 视觉后端 | Vision 懒加载视觉操作模型（点击/输入/定位），支持 GUI-Actor / GUI-Owl 双后端（按 `vision_mcp.backend` 选择，GUI-Owl 运行于 `.venv-owl`） |
| CDP | Chrome DevTools Protocol，DOM 优先的网页操作通道 |
| config.d 双向同步 | CharacterService 按 mtime 同步主配置与拆分文件，保留未知字段 |
| 关联性记忆★ | 用图谱边连接记忆节点（设计待实现） |
| 分级记忆 | L0 工作 / L1 短期(jsonl+live-context) / L2 长期(SQLite) / L3 知识固化 |
